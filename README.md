One haiku about debugging, in strict 5-7-5. A cursor blinks at 3am, a lone
breakpoint waits for dawn — and the last line reframes the whole night: the
bug was never in the code at all.

```
cursor blinks at three
a lone breakpoint waits for dawn
it was my typo
```

`main.ts` writes the haiku to `entry.txt` and validates it first: exactly
3 lines, 5-7-5 syllables, 1–200 characters.

## Run it

```sh
node main.ts
```
